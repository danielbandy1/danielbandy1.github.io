Financial Fraud Detection Pipeline

2026

End-to-end fraud detection pipeline on PaySim financial transaction simulation (2.77M CASH_OUT and TRANSFER transactions, 8,213 frauds). Enforces strict earlier-step transaction histories to eliminate future-data leakage. Evaluated on a forward-time holdout (steps >600, 43,550 transactions, 3.67% fraud rate) with a validation-fitted 10:1 cost-optimal threshold: post-transaction model achieves test Average Precision 0.8803 and AUROC 0.9956 (87.81% precision, 99.06% recall); in-line pre-authorization model (13 pre-event features, zero post-balance leakage) achieves test Average Precision 0.8366 and AUROC 0.9896 (83.33% precision, 99.06% recall).

  • Strict prior-step history feature store: rolling origin/destination velocity without future or same-step leakage
  • Prespecified temporal holdout: train (steps 1–500), validation (501–600), test (601–743)
  • Dual production models: in-line pre-authorization (AP 0.837) vs. post-settlement detection (AP 0.880)
  • Decision-theoretic validation cost thresholding (FN cost 1.0, FP cost 0.1) avoiding test snooping

Causal A/B Test Framework

2025–2026

Causal inference and decision-quality analysis of a website redesign experiment. Sanitized 294,478 raw events to 290,584 unique users by identifying and excluding 3,893 contaminated group/page mismatch telemetry rows. Verified assignment integrity via Chi-Square Sample Ratio Mismatch (SRM) test (χ² = 0.0045, p = 0.947). Conducted two-proportion z-testing (Δ = -0.158 pp, p = 0.190) and Beta-Binomial Bayesian conjugate inference (P(Treatment > Control) = 9.53%), showing redesign launch carries an unfavorable risk-reward profile.

  • Sample Ratio Mismatch (SRM) goodness-of-fit verification before metric evaluation
  • Two-proportion pooled z-test with 95% Wald interval and MDE power calculations
  • Beta(1,1) conjugate Bayesian posterior estimation with 1,000,000 Monte Carlo draws
